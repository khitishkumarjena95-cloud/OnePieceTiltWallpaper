# One Piece Tilt Wallpaper

Android live wallpaper project using the two images supplied by the owner.

## Build an APK on GitHub (phone-friendly)
1. Upload `OnePieceTiltWallpaper_Project_With_Your_Images.zip` from this chat into the repository's top level (Add file → Upload files).
2. Open the **Actions** tab.
3. Choose **Build Android APK** → **Run workflow**.
4. When the run finishes, open it and download the artifact named **OnePieceTiltWallpaper-debug-apk**.
5. Extract the downloaded artifact ZIP and install `app-debug.apk` on Android. If prompted, allow installs from your browser/files app.

The workflow compiles a debug APK and publishes it as a downloadable artifact.
